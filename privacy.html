1. ข้อมูลที่เก็บ

  • บัญชี Google: ชื่อ อีเมล และรหัสบัญชี (เฉพาะเมื่อเข้าสู่ระบบ) ระบบไม่เห็นและไม่เก็บรหัสผ่าน
  • ผลการตรวจเช็กเครื่อง AED: ผลแต่ละหัวข้อ หมายเหตุ รูปถ่าย และลายเซ็นของผู้ตรวจ
  • LINE (ถ้าเชื่อม): รหัสผู้ใช้และชื่อที่แสดงใน LINE เพื่อส่งข้อความแจ้งเตือน
  • การใช้งาน: วันเวลาที่เข้าสู่ระบบ การตั้งค่ารอบตรวจและการแจ้งเตือน และวันเวลาที่ยินยอมให้เก็บข้อมูล (สำหรับผู้ทดลองใช้)

ผู้ที่เปิดหน้าความรู้ (วิธีใช้เครื่อง AED / CPR) โดยไม่เข้าสู่ระบบ ระบบไม่เก็บข้อมูลส่วนบุคคล

2. วัตถุประสงค์

  • บันทึกและติดตามความพร้อมใช้งานของเครื่อง AED
  • แจ้งเตือนรอบตรวจและแจ้งเมื่อเครื่องไม่พร้อมใช้งานทาง LINE
  • การสาธิตและการศึกษาของหลักสูตร (ข้อมูลของผู้ทดลองใช้แยกจากเครื่อง AED จริง)

ระบบไม่ขาย ไม่โฆษณา และไม่ส่งต่อข้อมูลให้บุคคลภายนอก

3. ที่เก็บข้อมูลและผู้เข้าถึง

ข้อมูลเก็บใน Google Sheets และ Google Drive ของบัญชีหน่วยงาน เข้าถึงได้เฉพาะผู้ดูแลระบบ เจ้าหน้าที่เห็นเฉพาะข้อมูลของเครื่องที่ตนรับผิดชอบ ผู้ทดลองใช้เห็นเฉพาะข้อมูลของตนเอง ข้อความแจ้งเตือนส่งผ่าน LINE Messaging API

4. ระยะเวลาเก็บ

ผลการตรวจเช็กเครื่องจริงเก็บตลอดอายุการใช้งานของเครื่องเพื่อเป็นหลักฐานการบำรุงรักษา ข้อมูลของผู้ทดลองใช้เก็บไม่เกิน 1 ปี หรือจนกว่าจะขอให้ลบ

5. สิทธิของคุณ

คุณขอดู แก้ไข หรือลบข้อมูลของตนเอง และถอนความยินยอมได้ทุกเมื่อ โดยอีเมลถึง aedonecare.system@gmail.com และยกเลิกการเชื่อมแอปได้ที่ การเชื่อมต่อบัญชี Google

6. การใช้ข้อมูลจาก Google

ระบบขอเฉพาะสิทธิ์ openid, email และ profile เพื่อยืนยันตัวตนในการเข้าสู่ระบบเท่านั้น การใช้ข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use
